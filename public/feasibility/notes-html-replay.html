Exact Apple Notes HTML replay

This is an isolated experiment, not the Gym Logger app and not the normal Copy to Notes action.

What it does: it writes the exact captured text/html and matching text/plain representations that Apple Notes exposed. It does not sanitize or regenerate the HTML.

  1. Wait until the captured payload says it is ready.
  2. Tap Replay captured Notes HTML once.
  3. Return to the existing Apple Notes Gym note and paste.
  4. Check table editability, all five colours, Unicode, order, values, summary, and notes.
