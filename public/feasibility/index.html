Route 3 — Shortcuts conversion (requires USER-CREATED Shortcut)

No Shortcut is bundled with this project and none is assumed to exist. Create one first (one-time, free, ~2 minutes):

Shortcut A — “Gym HTML to Note” (clipboard input)

  1. Open the Shortcuts app → + → name it Gym HTML to Note.
  2. Add action Get Clipboard.
  3. Add action Make Rich Text (input: HTML from previous action).
  4. Add action Create Note (turn OFF “Show Compose Sheet”; folder: Notes).

Run: tap “Copy representative HTML source” above → open Shortcuts → run Gym HTML to Note → open the created note.

Shortcut B — share-sheet variant (file/text input)

  1. Create another shortcut ending in Make Rich Text → Create Note.
  2. Open the shortcut's details → enable Show in Share Sheet (receive: Text and/or Files).
  3. Run: use Share → Gym … on a downloaded .html file or on shared text.

Both variants carry NO paid Developer dependency and NO recurring install burden — exactly the E-003 constraint. Whether Make Rich Text keeps an editable TABLE and per-category COLORS is precisely what the device test decides.
