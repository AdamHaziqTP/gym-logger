## Required behavior corrections

### 1. Complete selected-row interaction

The current three-dot handle only opens the colour picker. Implement the approved interaction:

- First tap on a row handle selects the entire row and gives it a clear non-colour selection treatment.
- Tap the selected handle again to open a row menu.
- The menu exposes these commands with these user-facing labels:
  - `Add Row Above`
  - `Add Row Below`
  - `Duplicate Row`
  - `Copy`
  - `Cut`
  - `Paste` when a copied row is available
  - `Colour`
  - `Delete Row`
- Add Above/Below inserts a blank row with normalized positions.
- Duplicate creates an exact new row with a new identity and normalized positions.
- Copy/Cut/Paste operate on row data through an app-owned clipboard model; do not depend on the OS clipboard being available. Cut must remove the source row without losing the copied data.
- Paste is disabled or absent when no copied row exists and enabled when meaningful.
- Delete removes the selected row and normalizes positions. Preserve the existing optional undo policy; do not invent a destructive confirmation flow that conflicts with the spec.
- `Colour` opens the existing colour control and keeps the locked Arms/Back/Chest/Delts/Legs/None mapping.
- Implement touch/pointer drag on the selected handle for row reorder, normalize positions after reorder, and preserve all row data/highlight values.

Do not make every command a permanent button in each row. Keep the handle subtle but its hit target reliable on iPhone.

### 2. Resume the current session directly

When the app opens or remounts and a session already exists for today's local date, open that session directly instead of resetting the view to Home. Keep the `Gym Log` back control so the user can deliberately return Home. When no current session exists, retain the existing Home/Start flow.

### 3. Restore the approved category legend and visual treatment

- In the session header, render the category legend in the finalized content order: date → category legend → sets/exercises summary → table.
- Use the approved labels and mapping: `Arms` orange, `Back` purple, `Chest` mint, `Delts` blue, `Legs` pink, `Other`/None white.
- Compare row rendering to `GYM_LOGGER_SPEC.md` §5.2 and the supplied references. Keep bright category foreground text with a subtle dark/translucent highlight; do not use large bright solid full-row fills. Preserve readable dark Notes-like presentation.
