## 1. Baseline correction required by the acceptance criteria (disclosed)

The task's first protocol command (`npm test`) failed **24 pre-existing tests**
before any feasibility work could be claimed green. Root cause was identified,
reproduced with a throwaway diagnostic (deleted afterwards), and fixed with a
one-line production correction:

- **Defect:** `src/components/Home.tsx` `handleStart()` called
  `startTodaySession(db)` without the already-resolved `today` value, so Start
  always used the DEVICE date, violating the prop's documented contract
  ("Overrides today's local date; defaults to the device date") that App.tsx
  and CopySession.tsx both honor.
- **Why it was invisible until now:** every prior verification run happened on a
  device clock equal to the test fixture date (2026-08-24). Once the workstation
  clock advanced past that date, all DOM+Dexie flow suites looked up the started
  session under the injected date and found nothing.
- **Fix:** `startTodaySession(db, { dateLocal: today })` — restores the intended
  seam; no behavior change for normal device-date use. All 153 baseline tests
  pass again, including the domain test that pins the device-date default of
  `startTodaySession` itself.

No other production file was touched. The Copy to Notes path
(`src/domain/notesExport.ts`, `src/domain/notesClipboard.ts`,
`src/components/SessionView.tsx`) is byte-identical to the FIX-03 checkpoint.

## 5. Known limitations

- The harness cannot observe Share-Sheet targets or Notes conversions from the
  web context; completion of `navigator.share` is reported as mechanics only.
- Representative HTML is not byte-identical to the production payload (it
  restates the same markup style over the small fixture); if Route 3 succeeds,
  wiring the PRODUCTION payload through the winning transport is follow-up fix
  work outside this spike.
- RTF table support in Apple Notes on iOS has no public documentation; the
  generator maximizes interoperability signals (`\highlight` + `\chcbpat`,
  legacy-safe ASCII escapes) but success probability is unknown by design.
- jsdom cannot exercise real clipboard/share permissions; automated coverage
  proves classification honesty and payload contracts, not OS behavior.
