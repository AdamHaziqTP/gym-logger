## 1. Diagnosis

- Trusted HTTPS rich-paste retest on the iPhone 14 Pro Max (recorded in
  `orchestration/evidence/HUMAN-VERIFICATION-M03-T01.md`, "Recorded
  secure-origin retest result"): the editable Notes table survived with all
  values correct, but **no category text/highlight colors appeared**.
- The pre-FIX-02 payload put the entire category presentation on the row:
  `` <tr style="background-color:<bg>;color:<fg>"> ``. Apple Notes' HTML paste
  import converts web tables into native Notes tables and evidently drops
  container/row-level styling while keeping structure and text — consistent
  with how WebKit's attributed-string conversion privileges text-run-level
  formatting over ancestor styles.
- Correction therefore relocates the **exact same spec §5.2 tokens**
  (`HIGHLIGHT_TOKENS[highlight].fg/.bg`, unchanged values, single source of
  truth in `src/domain/highlights.ts`) onto the two markup levels closest to
  the text:
  1. each `<td>` gets `style="<padding>;background-color:<bg>;color:<fg>"`;
  2. each cell's content is wrapped in
     `<span style="color:<fg>;background-color:<bg>">…</span>`.
- This redundant encoding maximizes the chance at least one layer survives,
  without changing any color value, taxonomy, structure, or ordering.

## 3. Alternatives considered and rejected

- **Legacy `bgcolor` attribute / `<font color>`**: would require inventing new
  solid-hex constants (the tokens' backgrounds are translucent `rgba(…)`,
  which legacy attributes cannot express) — a second source of truth for
  category colors. WebKit normalizes both CSS inline styles and legacy
  attributes during paste import, so the expected benefit was marginal against
  the added duplication risk. Inline styles on td/text remain within the
  task's allowed conservative representation.
- **Pre-blending translucent backgrounds into solid hexes**: more predictable
  over an unknown Notes paper color, but deviates from the locked
  `HIGHLIGHT_TOKENS` values that AC-02 requires the payload to carry. Left as
  a possible follow-up decision if the device retest shows alpha backgrounds
  are the specific failure point.
- **RTF/native packaging, images, scripts, external CSS, classes**: out of
  scope per task constraints; none introduced.
