## Objective

Create the first real Gym Logger vertical slice so Codex can verify the orchestration loop against a working project:

1. A minimal React + TypeScript + Vite app that runs locally with documented scripts.
2. A local-first data layer using IndexedDB (Dexie is acceptable; keep dependencies small).
3. Seed the supplied latest session on first run without changing its free-form strings, row order, highlight values, or `40` / `39` summary override.
4. Home screen with `Last Workout`, `Start Today's Session`, `Continue Today's Session` when applicable, and a usable session entry point.
5. Start today's session uses the local date, creates one UUID session, clones row data/highlights and immediately persists it. It must be idempotent for today's date.
6. A dark, restrained, Notes-like fixed five-column table: `Exercise | Sets | Reps | Weight | Skip`.
7. Tapping/editing a cell accepts arbitrary text and autosaves it locally. Do not use numeric-only inputs or normalize spelling.
8. Row-level highlight rendering for `none`, `orange`, `purple`, `mint`, `blue`, and `pink`; include a compact row-level color control if a full Apple Notes-style row menu is out of scope for this task.
9. Show the summary with the fixture's manual override when present; skipped rows remain ordinary rows and count toward display totals.
10. Include a small notes area under the table that autosaves arbitrary text.

## Acceptance criteria

- AC-01: `npm install`, tests, and production build are documented and pass in the project root.
- AC-02: First launch creates a local seed from the supplied fixture; it visibly contains 40 rows and retains the source summary override `40` / `39`.
- AC-03: Start today's session creates exactly one session for the local date, clones values/order/highlights, and subsequent starts resolve to Continue rather than duplicating.
- AC-04: Every visible cell accepts arbitrary text including `body weight`, `8,6`, and `8.75 + 1 weight kg`.
- AC-05: Editing a cell and notes area persists through a reload using IndexedDB.
- AC-06: The table is usable at a narrow mobile viewport and visually follows the supplied dark Notes references: near-black background, subtle grid, colored text/highlight tokens, no dashboard cards or gradients.
- AC-07: No network/backend is required by the app's core runtime; do not use remote fonts, images, analytics, or polling.
- AC-08: OX reports changed files, commands run, results, limitations, and questions in `orchestration/reports/M01-T01.md`.
